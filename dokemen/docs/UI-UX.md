# UI/UX Specification

## Design Direction
Institutional, modern, clean, trustworthy, and appropriate for a hospital IT unit.

## Visual Principles
- Clear hierarchy
- Generous spacing
- Strong readability
- Consistent cards/tables/forms
- Accessible contrast
- Responsive design
- Avoid excessive animation

## Suggested Palette
Use hospital/institutional blue as the primary direction, with neutral backgrounds and restrained accent colors. Final brand colors should follow official RSUD/IT branding assets once provided.

## Components
Use reusable components for:
- Navbar
- Sidebar
- Breadcrumb
- Page header
- Stat cards
- Tables
- Filters
- Search
- Pagination
- Modal/confirmation
- Toast/flash messages
- Form fields
- Rich text editor
- File uploader
- Image preview
- Empty states
- Loading states
- Error states

## Responsive
Must work on:
- Desktop
- Tablet
- Mobile

## Accessibility
- Semantic HTML
- Keyboard accessible controls
- Visible focus states
- Alt text for meaningful images
- Labels for form fields
- Sufficient color contrast
- Do not communicate status using color alone
