# Content Structure

## Profile
- Sejarah
- Visi & Misi
- Struktur Organisasi
- Tugas & Fungsi
- Sarana & Prasarana

## Information
- Berita
- Kegiatan
- Pengumuman

## Documentation
- Foto/Galeri
- Video
- Dokumen

## Documents
Suggested categories:
- SOP
- Kebijakan
- Panduan
- SK
- Laporan
- Formulir
- Materi Pelatihan
- Dokumen Lainnya

## IT Services
Examples:
- User Support
- Hardware Support
- Software/System Support
- Network Infrastructure
- Server & Backup
- Information Security
- Printer/Peripheral Support

Final service names must be confirmed with the actual IT unit.

## Team IT
Each profile may contain:
- Name
- Position
- Department/Unit
- Photo
- Short biography
- Responsibilities (optional)
- Display order
- Published status
