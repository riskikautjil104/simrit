# SIMRIT Chasan Boesoirie

## Sistem Informasi Manajemen Ruang IT
RSUD Dr. H. Chasan Boesoirie Ternate

SIMRIT adalah sistem informasi berbasis web yang menjadi pusat informasi digital Ruang IT, mencakup profil, sejarah, visi dan misi, struktur organisasi, layanan IT, berita, kegiatan, pengumuman, dokumen, galeri foto, video, tim IT, dan pengelolaan konten.

## Technology
- Laravel 13
- PHP 8.3+
- Blade
- Livewire
- Tailwind CSS
- MySQL atau PostgreSQL
- Vite
- Laravel Filesystem

## Roles
- superadmin: akses penuh sistem
- admin: mengelola konten operasional, tanpa akses manajemen pengguna dan pengaturan sistem kritis
